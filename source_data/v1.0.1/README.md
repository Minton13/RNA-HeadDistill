# Source Data — RNA head-distillation manuscript (Nature Communications format)

Local review: the workbook and all 33 CSVs were independently checked for
matching cell values (8,117 data rows). The original build script and cluster
command below are archived provenance; rebuilding from the original raw
monorepo inputs requires that layout. Public workbook/CSV inspection does
not require executing that script or redrawing any frozen figure.

`SourceData.xlsx` contains one sheet per figure panel / table; `csv/` holds the
identical data as one standalone CSV per sheet (`csv/<SheetName>.csv`).
Everything is regenerated by `build_source_data.py` (this directory):

```bash
srun --nodelist=n3 --partition=batch --cpus-per-task=4 --mem=16G --time=00:30:00 \
    release/.venv/bin/python release/source_data/build_source_data.py
```

The workbook was validated after writing by reloading it with openpyxl:
**33 sheets, 8,117 data rows, no empty sheets** (validation summary is printed
by the script). All inputs are read-only; nothing under `rna_head_alignment/`
or `paper/` is modified.

## Conventions

- **Wide matrix sheets** (Fig2a_1–6, Fig2b, FigS2a–c): first column is the row
  key (`layer` or `task`), remaining columns are heads (`head_0…`) or tasks.
  Empty cells = missing/undefined values.
- **Indexing base**: Fig1a, Fig1c and Fig2a_1–6 use **0-based** layer/head
  indices (the convention of `all_head_atlas.csv` and the main figures).
  FigS2a–c use **1-based** indices (the old pilot project's convention,
  matching Supplementary Fig. S2 axis labels).
- Fig3b break-even rows carry fractional `n_experiments` (the computed
  break-even point, not a sample count).
- Significance stars (Fig4a/Fig4b): paired bootstrap vs P0, `***` =
  p_pos ≥ 0.999 or ≤ 0.001, else `ns` — the same rule as the figures.

## Deviations from the originally requested sheet list

- **Fig1c added** (six real attention maps shown in Fig. 1c); the list named
  only Fig1a.
- **FigS1a → FigS1a_nodes + FigS1a_links** (node and link schemas differ).
- **TableS4 → TableS4a/b/c** (route_finetune / multitask / alignment_replay)
  and **TableS5 → TableS5a/b** (alignment_ablation / alignment_ablation_delta):
  the source CSVs have incompatible schemas; one sheet per source file keeps
  every sheet tidy.
