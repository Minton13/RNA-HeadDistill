# Data access and cache policy — DRAFT

Status: AUTHOR_DECISION_REQUIRED. This draft establishes no new retention period, service level or transfer commitment.

Public code is MIT. The existing v1.0.0 derived-data package remains MIT, as originally published. Its student/MultiMolecule weight assets remain AGPL-3.0; PlantRNA-FM remains MIT. Author-created v1.0.1 documentation and aggregate Source Data are offered under CC BY 4.0. This grant does not relicense third-party inputs or labels.

The 8.8 TiB cache consists of selected full attention maps for the nine teachers over the distillation corpus; it is not a cache of all enabled models/tasks or a hidden-state release. v1.0.0 already states that it is available from the corresponding author upon request. Retention duration, responsible custodian, backups, eligible slices, transfer method, third-party conditions and response policy still require author confirmation; no new sharing guarantee is inferred here.

The 32 GB secondary-structure prediction files are index-only. Access and retention conditions for those files and pilot intermediates require author confirmation. Contact information may be requested from Boxue Tian (boxuetian@mail.tsinghua.edu.cn); availability and permitted redistribution must be assessed for each request.

NT-v2-500m and ModernGENA-base weights are not mirrored. Their exact source revisions are indexed; upstream access and licensing still apply.

Prediction artifacts include reference labels as well as model scores. A blanket CC BY statement for model outputs does not establish redistribution rights over every source label. The supplied provenance/rights uncertainty markers remain open. The rev2 prediction archive resolves the path collisions; reference labels remain subject to their source terms rather than the author-created output grant.
