# RNA-HeadDistill v1.0.1 reproducibility supplement

This release supplements the unchanged [v1.0.0 original study artifacts](https://github.com/Minton13/RNA-HeadDistill/releases/tag/v1.0.0).
No stored model checkpoint, reported measurement, or frozen Figure 1–4 is changed.
Plotting code is archived as provenance; no frozen figure was redrawn during local release verification.

## Release assets

Download the three attachments from [v1.0.1](https://github.com/Minton13/RNA-HeadDistill/releases/tag/v1.0.1):

| Attachment | Contents |
|---|---|
| `code-overlay-and-docs_v1.0.1.tar.gz` | Reviewed code overlay, tests, documentation and screening patch; generated bytecode excluded |
| `metadata-and-sourcedata_v1.0.1.tar.gz` | 22-row provenance, checkpoint/license/metric indices, corrected prediction paths, 135 per-seed point values, SourceData.xlsx (33 sheets / 8,117 rows) and matching CSVs |
| `downstream-predictions_v1.0.1.tar.gz` | 241 unique files across five tasks and nine configurations: 135 test files and 106 existing validation files |

Extract the metadata and prediction archives into the same directory so `metadata/`, `source_data/` and `predictions/` are siblings. Install the checked-out code with `pip install -e .`. The code overlay is intended for the verified v1.0.0 baseline; use the tagged repository directly for the complete version.

The server-wide index contains 162 test and 133 existing validation entries across six tasks; these totals include 54 secondary-structure index-only records and must not be called public prediction-file counts. There are 29 documented missing validation records (27 chemical-reactivity, two ncRNA). P4g uses `distilled_hidden_aligned_gated/`; A8-P4g uses `distilled_hidden_aligned_gated_a8/`. All 241 packaged entries pass size/SHA256 verification.

## Reviewed code changes

- Attention conversion uses `.detach().cpu().numpy()` for CUDA and gradient-carrying tensors.
- Screening failures log model/task/sample identifiers and traceback.
- Explicit annotated split filtering occurs before the sample cap; legacy prefix sampling remains the default. Pairwise JSONL filtering is streamed.
- Prediction validation rejects missing files, mismatched hashes and configuration path collisions before metric replay.
- Missing required replay files are errors, including in gated-config replay. Deliberately unshipped secondary-structure cells are separately reported.
- Train-only re-ranking accepts public package paths instead of requiring the private monorepo layout.

## Reproduction commands

```bash
curl -LO https://github.com/Minton13/RNA-HeadDistill/releases/download/v1.0.0/dataset-rna-head-distill_v1.0.0.tar.gz
tar -xzf dataset-rna-head-distill_v1.0.0.tar.gz
export RNA_HEAD_DISTILL_DATA="$PWD/dataset-rna-head-distill"
export PYTHONPATH="$PWD/src"
python -m pytest
python scripts/reproduction/reproduce_tables.py --outdir outputs/reproduction
python analysis/trainonly_secondary_rerank.py --outdir outputs/reproduction/trainonly
python analysis/verify_prediction_archive.py --index metadata/prediction_archive_index.csv --root . --out index_check.json
python analysis/replay_downstream_metrics.py --pred-root predictions --points-csv "$RNA_HEAD_DISTILL_DATA/metrics/downstream/downstream_recomputed_points.csv" --gated-points-csv metadata/downstream_perseed_points_p4g_a8.csv --out replay_report
```

Local validation: **88 tests passed**, including actual CUDA tensor tests on an RTX 3070; **408/408 metric checks matched** (273 against the original v1.0.0 point table plus 135 against the nine-configuration primary-point table). These cover 135 unique task/configuration/seed cells; the two gated configurations each cover 15/15 cells. Maximum absolute error was 9.103828801926284e-15 at tolerance 1e-6. Twenty-one secondary-structure cells in the original replay table are deliberately NOT_PACKAGED. This is per-seed metric verification; it is not a claim that every bootstrap confidence interval has been rerun.

Train-only re-ranking reproduces 6,604 rows / 28 models, top-30 overlap 25/30 and the two selected secondary-structure heads at ranks 1/2. The 15-head bank is unchanged.
